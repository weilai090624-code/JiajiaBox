请求目标 IP 仅在原生后台线程查询并按国家／地区汇总。为显示本机与实际节点出口位置，原生内核按直连及当前连接的实际出站分别请求 HTTPS 公网 IP 回显服务（api.ipify.org，失败时使用 www.cloudflare.com/cdn-cgi/trace），复用内核出站并保持 TLS 验证。服务自然可见该次请求的源公网 IP；不会向服务提交用户请求的域名、目标 IP、流量明细、节点凭证或 GPS 坐标。查询仅由可见地球触发，并发上限为 3，成功缓存 3 分钟，失败 45 秒后可重试；不改变当前选择的节点。网页只接收国家代码、连接数量、国家代表位置、匿名出口标识、聚合连线和主题状态，不接收原始 IP、域名或内核令牌。贴图由原生后台线程读入并以内联 data URL 提供；内嵌网页禁止网络请求、外部导航、文件和内容访问，不请求 GPS 权限。

此图是连接地理分布示意，不是 traceroute，不展示真实网络跳数、海底光缆或物理路由。本机点按直连公网 IP 所在国家显示，不使用 GPS；出口按该实际出站访问回显服务时观测到的公网 IP 分组，请求点按目标 IP 所在国家显示。显示点是国家／地区代表位置，并非 IP 城市坐标。出口会随目的地、IPv4/IPv6 和服务商路由变化，显示的探测结果不能保证适用于每一个目标。较多条目可滚动查看。私网、链路本地、Fake-IP、缺少真实目标 IP 和数据库无法识别的连接计入“未定位”。地图不表示国界，昼夜光照根据设备当前 UTC 时间计算太阳赤纬、均时差和太阳直射经纬度；计算参考 NOAA Solar Calculation Details（https://gml.noaa.gov/grad/solcalc/calcdetails.html）。太阳方向固定在地理坐标系，每 15 秒更新，拖动与自转不改变同一经纬度的昼夜状态。此效果不表示实时天气；设备时钟错误会影响昼夜判断。

无连接时仍可预览地球，不生成演示连接。支持缓慢自转、交互阻尼、松手惯性、双指缩放和国家定位，可在右上角暂停自转。离屏、后台或抽屉运动时暂停；动画最多约 30 帧/秒，关闭自转且交互停稳后不持续绘制。

连线按“本机 → 实际出口 → 请求国家”展示，同一公网出口的多个节点复用一条前半段；同一出口访问同一国家复用一条分支并累计连接数。不同出口分别保留；直连请求从本机直接连至目标国家。无法确认本机、出口或目标国家时不编造位置或线路。

每段连线的起点和终点都落在球面：本机起飞后在出口落地，再从同一出口位置起飞，在请求国家落地。共享出口的主干和按国家合并的分支规则保留。球体轮廓使用解析像素覆盖和平滑透明合成，小视口最高按 3 倍像素比绘制；贴图使用三线性 mipmap 过滤，弧线使用更密采样与圆角连接。

显示分组分别保留 CN（中国大陆）、HK（香港）、TW（台湾）与 MO（澳门），不将地区代码并入 CN。中文使用简短显示名，避免窄列表中长名称被截成相同前缀；国家／地区坐标与按出口聚合规则保持独立。底部摘要仅显示当前连接数量，地理精度和数据说明保留于本说明。
